Hisho — Agent Evaluation

A hands-free work agent for the car, and the harness that measures it. Consequential actions — sending mail, moving or cancelling meetings — are gated in application code rather than by prompt instruction, and the sentence the user hears before approving one is generated by the policy layer, not by the model. Every run below is the product agent, constructed by the same build_agent() the CLI uses, against a resettable mock calendar, inbox and course list.
